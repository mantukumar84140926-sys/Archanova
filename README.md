# AJEDUVERSE

**A Universe of Free Learning — Learn · Grow · Succeed**

AJEDUVERSE is a bilingual learning platform for school, college and competitive-exam students.

## Website MVP

This repository contains the first responsive website experience:
- Responsive landing page for desktop and mobile
- Learning-path cards for school, college and competitive exams
- Search and category filters
- Feature overview for notes, videos, MCQs, AI doubt help and progress tracking
- Hindi + English positioning and a 100% free-learning promise

> Course content, accounts, tests, dashboards, notifications and AI doubt-solving are planned for later phases. The current homepage does not claim these backend features are already live.

## Run locally

Requirements: Node.js 20.9+

```bash
npm install
npm run dev
```

Open http://localhost:3000.
